# BBW Platform

Stage 1 is a Node 24, pnpm, and Turborepo monorepo. Start with
[`CONTRIBUTING.md`](./CONTRIBUTING.md) for the verified setup, local-service,
test, and troubleshooting workflow.

The previous website design and supporting code are archived in
[`demo/`](./demo/README.md). Treat that directory as read-only reference
material; all new platform code lives outside it.

Local environment values remain in the ignored root `.env.local` file so they
are not copied into the archive or committed accidentally.
