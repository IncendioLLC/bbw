# ADR-0000: Decision title

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Deciders:** Names or roles
- **Supersedes:** None
- **Superseded by:** None

## Context

Describe the problem, constraints, and forces that make a decision necessary. Include only the alternatives and evidence needed to understand the choice.

## Decision

State the chosen approach and the boundaries it establishes. Use clear, testable language.

## Consequences

- **Positive:** Benefits created by the decision.
- **Negative:** Costs, risks, or trade-offs accepted.
- **Follow-up:** Work or validation required after adoption.

## Supersession

Do not rewrite an accepted ADR when the decision changes. Create a new ADR, set this record's status to `Superseded`, populate **Superseded by**, and have the replacement populate **Supersedes**.
